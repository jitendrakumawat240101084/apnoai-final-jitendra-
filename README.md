# ApnoMart Sales Dashboard

## Project Overview
An interactive sales analysis dashboard created using Microsoft Power BI.

## Tools Used
- Microsoft Power BI
- DAX
- Data Visualization

## Project Files
- `dashboard.png` – Dashboard screenshot
- `ApnoMart.pbix` – Power BI dashboard source file
- `data.csv` – Dataset
- `insight.pdf` – Business insights report

## Key Features
- Revenue Analysis
- Profitability Analysis
- Customer Segmentation
- Discount vs Profit Scatter Plot
- Interactive Visualizations
